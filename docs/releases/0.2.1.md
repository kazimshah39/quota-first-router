# Quota First Router 0.2.1

This patch improves the Account quota monitor. It does not change routing, failover, or warmup behavior.

- Accounts are grouped by routing tier, with the priority shown beside each tier heading. Inside each tier, the monitor follows the saved Oh My CPA Routing order when available and otherwise sorts alphabetically. The **Selected** badge stays on the picked card without moving it.
- **Last read** and **Next attempt** appear once under **Account quota**. The per-card **Details** toggle is gone; polling errors remain visible, and exhausted cards keep their red border and warning icon.
- The seven-day quota is labeled **Weekly**. Monthly-only accounts still show **Monthly allowance**. A single visible card keeps its normal column width on wider screens.

Install through the CLIProxyAPI plugin store, or download the matching ZIP and verify it against `checksums.txt`. Do not overwrite a native library that CLIProxyAPI may still have loaded. See the [operations guide](https://github.com/kazimshah39/quota-first-router/blob/v0.2.1/docs/operations.md) for upgrades and the [monitor guide](https://github.com/kazimshah39/quota-first-router/blob/v0.2.1/docs/monitor.md) for what the dashboard shows.
