# 0.1.2 — six-platform release

All six required platforms passed matching native CPA 8.1.0 acceptance, including exact ZIP local-store installation, routing/polling and rollback. Full native evidence and hashes are linked below. Public download/store and deployment results are tracked in release status. Existing releases are immutable; monitoring remains deferred.

## Changes

- Generic six-target builds, deterministic flat ZIPs, sorted complete SHA-256 manifest.
- ELF64/Mach-O64/PE32+ architecture/export/dependency/minimum checks and rejection tests.
- Pinned Zig 0.15.2, LLVM-MinGW 20261117 UCRT, SDK 26.1 and Go 1.26.10; isolated Darwin-amd64 TLS-slot toolchain and disassembly check.
- Portable synthetic native CPA 8.1.0 acceptance with exact candidate ZIP/store install, authenticated status, shadow/active routing, streaming/concurrency, polling, tier recovery and disable rollback.
- Nonpublishing six-native-runner CI and exact-source/hash-bound artifact aggregation. Manual separately approved publication only.
- Correct closed-store-PR status and defer monitoring. No policy/quota/bridge changes other than the plugin version.
