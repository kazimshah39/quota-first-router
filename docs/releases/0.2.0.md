# Quota First Router 0.2.0

- **Account quota dashboard:** See how much quota is left, reset timers, routing activity, and polling errors. Filter by **All**, **Available**, **Exhausted**, or **Free**. Open **How it works** for simple examples. Refresh reads saved data; it does not trigger provider checks or inference.
- **Free plans:** The router skips provider-confirmed Free accounts in automatic Codex-only routing and warmup. They still appear in the dashboard. Explicit pins and mixed-provider requests remain under CPA’s control.
- **Optional five-hour warmup:** When enabled, the plugin can send one small, pinned request to an eligible idle account, including one already idle at startup. It uses a little quota, does not add quota, and defaults to **GPT-6 Luna**. It requires a local CPA management endpoint and private state files. Warmup is off by default and is available on Linux and macOS, not Windows.
- **Simpler settings:** CPA’s **Enabled** switch controls the router. The main settings form has one plugin-specific switch for warmup; advanced settings remain in JSON or YAML.

The router still starts with the highest usable account priority and prefers the soonest five-hour reset within that tier. **Selected** is the plugin’s pick, not proof of which account served the request. The dashboard’s account data requires CPA management authentication.

## Before upgrading from 0.1.x

Disable the old plugin and remove the legacy `mode` setting before loading 0.2.0. Leave the plugin disabled until you want it to route requests. Do not overwrite a library that CPA may have loaded. See the [upgrade and warmup guide](https://github.com/kazimshah39/quota-first-router/blob/v0.2.0/docs/operations.md).

Download the ZIP for your platform and verify it against `checksums.txt`. Packages cover macOS, Linux, and Windows on both amd64 and arm64. The native acceptance baseline is CPA 8.1.0. See [platform limits](https://github.com/kazimshah39/quota-first-router/blob/v0.2.0/docs/platform-support.md) and the [monitor guide](https://github.com/kazimshah39/quota-first-router/blob/v0.2.0/docs/monitor.md).
