# Quota First Router v0.1.1

Quota parsing and validation fixes; the tier-first policy and default one-minute polling are unchanged.

- Recognize array and object additional-limit payloads, camelCase window fields, and normal-model slugs.
- Match model quotas exactly rather than by substring; keep all duplicate meter windows so an exhausted meter cannot be overwritten.
- Respect account spend-control exhaustion.
- Reject malformed reset/duration/boolean quota fields and invalid configured proxy URLs instead of accepting misleading usable data.
- Prefer exact JSON field spellings and fall back from empty optional model-name fields.
- Make the optional live canary inspect an installed library rather than overwrite a potentially mapped native library.
- Add randomized tier-order tests, fuzz coverage, stale boundaries, credential recovery checks, a selection benchmark, mixed Responses/Chat Completions streaming tests, and upstream-error failover checks.

Supported platform remains CPA 8.1.0, Linux amd64 with glibc 2.34 or newer. Installations default to shadow mode. See `docs/test-matrix.md` for measured coverage and limits; no claim of exhaustive provider or platform support.
